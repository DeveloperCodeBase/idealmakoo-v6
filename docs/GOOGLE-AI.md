# درگاه Google AI

## اجرا و تنظیم

صفحات همچنان با Next.js و TypeScript ساخته می‌شوند. `npm run build` ابتدا خروجی `out/` را می‌سازد، سپس `scripts/build-worker.mjs` صفحات را در `dist/client` و درگاه ESM را در `dist/server/index.js` قرار می‌دهد. این تغییر برای نگهداری کلید در سرور لازم است؛ کلید هیچ‌وقت `NEXT_PUBLIC_` ندارد.

برای اجرای محلی، `.env.example` را به `.env.local` کپی و `GOOGLE_AI_API_KEY` را تکمیل کنید. سپس:

```bash
npm ci
npm run build
npm start
```

سایت در `http://127.0.0.1:3000/fa/` در دسترس است. سرور محلی متغیرهای `.env.local` را می‌خواند و برای تصاویر از مسیر نادیده‌گرفته‌شدهٔ `.sites-runtime/generated/` استفاده می‌کند. `npm run dev` توسعهٔ رابط Next را اجرا می‌کند؛ برای آزمون AI از `npm start` استفاده کنید. در میزبانی فعلی، همان کد در Worker و تصاویر در `BUCKET` اجرا می‌شوند. هیچ کلید محرمانه‌ای در بستهٔ سورس موجود نیست.

| متغیر سرور | مقدار پیش‌فرض |
| --- | --- |
| `GOOGLE_AI_API_KEY` | تعریف‌نشده؛ باید در محیط سرور تنظیم شود |
| `GOOGLE_AI_TEXT_MODEL` | `gemini-3.5-flash-lite` |
| `GOOGLE_AI_IMAGE_MODEL` | `gemini-nano-banana-2.1` |

## مسیرهای پیاده‌شده

| مسیر | کاربرد |
| --- | --- |
| `GET /api/ai/status` | وضعیت وجود تنظیمات، نام مدل‌ها و تعداد رکوردهای منابع؛ بدون کلید |
| `POST /api/ai/chat` | گفتگوی چندمرحله‌ای، پاسخ عمومی و راهنمای سایت همراه منابع |
| `POST /api/ai/generate` | تولید متن، بازنویسی، ترجمه، سند، تصویر و متن سناریوی صوت/ویدئو |
| `GET /api/ai/media/{id}` | دریافت تصویر تولیدشده در محدودهٔ هویت مالک آن |

ورودی JSON شامل `prompt`، `locale` و `mode` است. `history` فقط نقش‌های `user` و `model` را قبول می‌کند. برای ویرایش تصویر از `imageData: {mimeType,data}` یا مسیر تصویر محصول در `referenceImage` استفاده کنید. قالب‌های مجاز PNG، JPEG و WebP هستند. `context` برای متن فعلی ویرایشگر یا نمای منتشرشدهٔ سایت است. هیچ ابزار اجرایی، دسترسی فایل یا جستجوی زندهٔ وب در اختیار مدل قرار نگرفته است.

خروجی موفق شامل `id`، `text`، `model`، `provider`، `sources` و در حالت تصویر `image: {url,mimeType,bytes}` است. نبود تصویر در پاسخ یک درخواست تصویری، خطای `NO_IMAGE` می‌دهد؛ متن پاسخ به‌جای فایل تصویر ذخیره نمی‌شود. صوت و ویدئو فقط متن سناریو می‌سازند و رابط همین موضوع را صریح نمایش می‌دهد.

## منابع و رفتار پاسخ

`worker/knowledge.ts` محصولات، پژوهش‌ها، صفحات کارخانه، ۳۰ برگهٔ اصلی، هر دو PDF و بخش‌های آن‌ها، متن ۴۳ صفحهٔ مرجع و راهنمای مسیرها را به رکوردهای قابل بازیابی تبدیل می‌کند. عنوان‌ها و خلاصه‌های پنج‌زبانه برای جستجو استفاده می‌شوند؛ متن اصلی اسناد و واحدهای نامشخص جدا نگه داشته شده‌اند. جستجو، حروف فارسی/عربی و نشانه‌ها را یکسان می‌کند و رکوردهای مرتبط را همراه شناسهٔ منبع در اختیار مدل می‌گذارد.

پرسش‌های عمومی مجازند. برای ادعا دربارهٔ کارخانه، مدل باید به اطلاعات ثبت‌شده اتکا کند و قیمت، موجودی، گواهی جاری یا خانهٔ خالی جدول‌ها را حدس نزند. پاسخ‌ها با منابع شماره‌دار و پیوند صفحه نمایش داده می‌شوند. متن مدل از طریق React رندر می‌شود؛ HTML تولیدشده اجرا نمی‌شود و آدرس‌های اجرایی پذیرفته نیستند.

## مرزهای عملیاتی

کلید فقط در هدر `x-goog-api-key` درخواست HTTPS به `generativelanguage.googleapis.com` قرار می‌گیرد. پاسخ خام خطای Google به مرورگر برنمی‌گردد. درگاه نوع و اندازهٔ ورودی، تعداد/اندازهٔ سابقه، منشأ درخواست، زمان انتظار و درخواست‌های همزمان را کنترل می‌کند. درخواست با خروج کاربر یا توقف لغو می‌شود. محدودیت فعلی ۱۸ درخواست در دقیقه و دو درخواست همزمان در هر isolate است؛ محدودیت توزیع‌شده و حسابداری مالی مصرف نیست.

میزبانی موجود فقط برای مالک باز است. هویت معتبر تزریق‌شدهٔ میزبان برای تصاویر استفاده می‌شود؛ درخواست سرویس خصوصی بدون هویت بازدیدکننده محدودهٔ مجزای خودش را دارد. نقش‌های پنل نمونه همچنان قرارداد فرانت‌اند هستند و کلید عمومی یا توکن معتبر API تولید نمی‌کنند. قبل از عمومی یا چندکاربره کردن این سرویس، احراز هویت واقعی، مجوز فراخوانی ابزارها، سهمیهٔ پایدار و سیاست انتشار رسانه را در بک‌اند خودتان متصل کنید.

تاریخچه و پیش‌نویس پنل در مرورگر ذخیره می‌شوند. خروجی تصویر میزبانی‌شده در R2 است. ذخیرهٔ پیش‌نویس، افزودن به رسانه و ارسال برای بازبینی با مجوز جاری رابط کنترل می‌شوند؛ تغییر نقش/حساب نتیجهٔ دیررس را بی‌اثر می‌کند. انتشار خودکار نتیجهٔ مدل انجام نمی‌شود.

## نتیجهٔ آزمون سرویس در ۲۰۲۶-۱۰-۱۷

دریافت فهرست مدل‌ها HTTP 200 و فراخوانی متن مدل `gemini-3.5-flash-lite` پاسخ واقعی HTTP 200 داد. مدل `gemini-nano-banana-2.1` و مدل سبک‌تر `gemini-3.1-flash-lite-image` هر دو از `generateContent` پشتیبانی می‌کردند، اما فراخوانی تصویر برای کلید ارائه‌شده با HTTP 429 و `RESOURCE_EXHAUSTED` متوقف شد. پاسخ مدل سبک‌تر محدودیت‌های Free Tier توکن، تعداد درخواست دقیقه و روز را گزارش کرد. تصویر واقعی در این آزمون ساخته نشد و دریافت آن تأییدشده نیست. این مانع با فعال‌شدن سهمیهٔ تصویر در همان حساب Google رفع می‌شود؛ تعویض رابط یا قرار دادن کلید در مرورگر راه‌حل آن نیست.

آزمون‌های خودکار در `tests/ai-gateway.test.mjs` قرارداد واقعی درگاه را با پاسخ کنترل‌شدهٔ Google بررسی می‌کنند: خروجی متن، عبور مرجع ویرایش تصویر، نگهداری تصویر و مالکیت، خطای سهمیه، عدم افشای کلید، منشأ نامعتبر، توقف و همزمانی. این آزمون‌ها مصرف سرویس واقعی ندارند.

منابع فنی: [REST API](https://ai.google.dev/api/generate-content)، [مدل‌ها](https://ai.google.dev/gemini-api/docs/models)، [تولید تصویر](https://ai.google.dev/gemini-api/docs/image-generation)، [کلیدهای API](https://ai.google.dev/gemini-api/docs/api-key).

## سازگاری درخواست در میزبان

محیط میزبانی در آزمون واقعی، `redirect: 'error'` را نمی‌پذیرفت و پیش از تماس با Google خطا می‌داد. درگاه از `redirect: 'manual'` استفاده می‌کند و هر پاسخ خارج از بازهٔ موفقیت را رد می‌کند؛ کلید به مقصد هدایت‌شده ارسال نمی‌شود. فراخوانی پیش‌فرض نیز از `globalThis.fetch(...)` استفاده می‌کند تا گیرندهٔ تابع حفظ شود. گزارش خطای سرور مرحله و پیام کوتاهِ پالایش‌شده دارد، بدون متن درخواست یا کلید. آزمون بازگشت ۳۰۲، عدم دنبال‌کردن آن را کنترل می‌کند.

فهرست رسمی ۱۷ سری محصول یک رکورد مستقل دارد و برای پرسش‌های مربوط به محصولات در هر پنج زبان، پیش از برگه‌های PDF انتخاب می‌شود. این انتخاب از اشتباه‌گرفتن دسته‌های قالب با نام سری محصول جلوگیری می‌کند. رکورد، نام و مسیر واقعی تمام محصولات را دارد و محصول جدیدی از روی PDF ایجاد نمی‌کند.
