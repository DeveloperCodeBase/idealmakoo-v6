# اصلاح چهارم — Liquid Glass Neon و هیروی یکپارچه

این اصلاح، ظاهر مشترک سایت و پنل‌ها و ترکیب هیروی صفحهٔ اصلی را بازطراحی می‌کند. متن معرفی دیگر بخش مستقلی بالای صحنه نیست؛ تیتر، شعارهای متحرک، معرفی کوتاه و دکمه‌های محصول و کاتالوگ روی همان فضای تمام‌عرض دندان‌های شناور قرار دارند.

## رنگ و جنس سطوح

| عنصر | حالت تیره | حالت روشن |
| --- | --- | --- |
| زمینه | جوهر تیره `#080b14` | صدفی سرد `#f2f5fc` |
| سطح برجسته | `#151d30` | `#f9fbff` |
| متن اصلی | `#f2f5ff` | `#17233d` |
| تأکید خوانا | آبی یخی `#9be8ff` | نیلی `#244a9b` |
| تأکید دوم | بنفش ملایم `#b2a5ff` | بنفش جوهری `#6252ac` |
| دکمهٔ اصلی | جوهر تیره روی شیشهٔ یخی | متن سفید روی نیلی |

لبهٔ روشن و باریک، انعکاس روی سطح، تاری پشت شیشه و سایهٔ عمیق، حس مرطوب را می‌سازند. رنگ تابش نئون از رنگ متن جداست تا متن حالت روشن کم‌رنگ نشود. همان نشانگر مشترک، انعکاس را روی کارت، دکمه، ناوبری و سطوح پنل جابه‌جا می‌کند. پس‌زمینهٔ میزکار انیمیشن محیطی دائمی ندارد.

منوها، دیالوگ‌ها، داک کروسل، کارت‌های پنل، دکمه‌های عملیاتی و رنگ وضعیت‌ها از همین توکن‌ها استفاده می‌کنند. هندسه و ژست‌های کروسل و مکان‌یابی دیالوگ‌ها در این اصلاح تغییر نکرده‌اند.

## هیرو و پنج زبان

`ImmersiveHero.tsx` تنها ترکیب آغاز صفحه را می‌سازد. `Home.tsx` همچنان عنوان، توضیح، دکمه‌ها و تصویر اختیاری را از بلوک `home-hero` در زبان انتخاب‌شده می‌خواند. متن پیش‌فرض کوتاه‌تر شده؛ محتوای منتشرشدهٔ اختصاصی CMS بازنویسی نمی‌شود.

- فارسی و عربی: متن در سمت راست، دندان‌ها در فضای آزاد سمت چپ.
- انگلیسی، ترکی و روسی: متن در سمت چپ، دندان‌ها در فضای آزاد سمت راست.
- صفحه‌های باریک‌تر از ۹۶۰ پیکسل: متن و فضای تعامل در یک صحنه و دو ردیف قرار می‌گیرند؛ ارتفاع متن ثابت فرض نمی‌شود.

دوربین فضای آزاد واقعی DOM را اندازه می‌گیرد. همان دوربین برای نمایش، گرفتن دندان با ماوس و مکان نشانگر Ai Agent استفاده می‌شود. تغییر اندازهٔ صفحه، محل فیزیکی دندان‌ها را عوض نمی‌کند. نمای جایگزینِ نبود WebGL نیز از فضای اندازه‌گیری‌شده پیروی می‌کند.

عنوان بدون انیمیشن نیز خواناست. انیمیشن روی خط کامل اجرا می‌شود تا اتصال حروف فارسی و عربی حفظ شود. متن عنوان از درخت دسترس‌پذیری حذف نمی‌شود. با تنظیم Reduced Motion یا پنهان‌شدن صفحه، حرکت تزئینی متوقف می‌شود. عنوانی که ویرایشگر عمداً خالی کرده، یک H1 خالی تولید نمی‌کند.

برای تغییر چیدمان صحنه از `composition="landing"` و `framingRegionRef` استفاده شده است؛ حالت پیش‌فرض مؤلفه برای بقیهٔ محل‌های استفاده حفظ شده است. برای برگشت محصول به مجموعه‌ها، اگر بخش خانواده‌ها مخفی باشد، لینک پایین هیرو به مقصد اصلی محصولات می‌رود.

## دامنهٔ کنترل

فایل‌های CSS بازطراحی‌شده با PostCSS تجزیه شده‌اند. کنتراست رنگ‌های پایه و دکمه‌ها محاسبه شده است؛ این محاسبه مشاهدهٔ تصویر رندرشده یا آزمون دسترس‌پذیری کامل صفحه نیست.

مرورگر کنترل‌شده در محیط ساخت در دسترس نیست. مشاهدهٔ بصری واقعی در دسکتاپ/گوشی، عملکرد GPU، لمس و WebGL روی دستگاه آزمایش نشده‌اند. بررسی کد، هندسه، خروجی ساخت و آزمون خودکار، جای این مشاهده را نمی‌گیرد.

مدل‌های دندان همچنان هندسهٔ تألیفی‌اند؛ اسکن سه‌بعدی محصول نیستند. Ai Agent همان موتور حرکت فرانت‌اند است و برای این تعامل به درخواست API وابسته نیست.

### کنترل‌های انجام‌شده

- ۲۲۳ آزمون خودکار از ۲۲۳ آزمون موفق بود؛ صفر شکست، حذف یا تعلیق.
- بررسی مستقل TypeScript بدون خطا بود.
- ۲۹ آزمون صحنه شامل چهار آزمون تازه برای جهت قاب‌بندی، اندازه‌گیری DOM، تطابق پرتو انتخاب و جاگیری مدل در گردش کامل است.
- فایل‌های CSS اصلاح‌شده با PostCSS تجزیه شدند و `git diff --check` بدون خطا بود.
- کنتراست متن اصلی نسبت به زمینه در حالت تیره ۱۸٫۰۵:۱ و در حالت روشن ۱۴٫۳۱:۱ محاسبه شد. کمترین کنتراست محاسبه‌شدهٔ دکمهٔ روشن همراه با لایهٔ بازتاب ۴٫۵۲:۱ است؛ این نسبت مربوط به مدل رنگ‌هاست، نه تمام پیکسل‌های صفحهٔ واقعی.
- بازبینی مستقل، نمایش پیام درست در حالت نبود WebGL، راهنمای صفحه‌کلید، پنج زبان و لینک جایگزین هنگام پنهان‌بودن مجموعه‌ها را تأیید کرد.

### ساخت و خروجی نهایی

- بیلد کامل Next.js 16.4.2 با Webpack و بررسی نوع زمان ساخت موفق بود.
- ۱٬۱۰۰ مسیر در پنج زبان و ۷۹ مسیر جایگزین مدیریت، خروجی معتبر دارند؛ در مجموع ۱٬۱۸۳ سند HTML تولید شد.
- ۵۲٬۴۸۷ ارجاع محلی به ۸۵۷ مقصد موجود و ۱۳ فایل CSS کنترل شد.
- ساختار HTML صفحهٔ اصلی در هر پنج زبان، یک هیروی یکپارچه، عنوان خوانا، جهت درست و دو دکمهٔ اصلی دارد؛ بلوک `home-hero-header` قدیمی دیگر وجود ندارد.
- بستهٔ Worker دارای ۱۵۸ ورودی دانش است و تنظیمات محرمانهٔ سرور داخل خروجی نوشته نمی‌شوند.
- ZIP قابل استخراج و SHA-256 همهٔ فایل‌های داخل آن با سورس تطبیق داده شد. نسخهٔ خروجی و قطعه‌های دانلود هنگام بسته‌بندی دوباره با همان ZIP هماهنگ می‌شوند.

این کنترل‌ها فایل و کد را بررسی می‌کنند؛ مرورگر واقعی اجرا نشده است.

## اجرای محلی

```bash
npm ci
npm test
npm run build
npm start
```

نشانی نمونه: `http://localhost:3000/fa/`. تغییر زبان و تم از ناوبری انجام می‌شود. مسیر صفحهٔ اصلی در هر پنج زبان همان `/{locale}/` است.

درگاه AI، اسناد، آرشیو منابع و قرارداد بک‌اند نسخهٔ قبل حفظ شده‌اند؛ [راهنمای اصلاح سوم](REVISION-3-GUIDE.md) و [قرارداد بک‌اند](BACKEND-CONTRACT.md) جزئیات آن‌ها را توضیح می‌دهند.
