# پلن اجرای فرانت‌اند ایده‌آل ماکو

## محدودهٔ مصوب
درخواست فعلی مالک بر سند مقدم است: **فقط فرانت‌اند Next.js و TypeScript**. تمام صفحه‌ها، فرم‌ها، ناوبری، گردش‌های تعاملی و قراردادهای داده ساخته می‌شوند. عملیات سرور (احراز هویت امن، ارسال پیام واقعی، تولید هوش مصنوعی، دیتابیس، اسکن فایل، SLA و محاسبات تراکنشی) از طریق رابط‌های مستقل قابل اتصال خواهند بود؛ نمایش رابط این امکانات به معنی اجرای سرویس سرور نیست.

## مراحل و خروجی‌ها

| فاز | خروجی مشخص | کنترل تکمیل |
|---|---|---|
| 01 — منابع | خواندن سند و هر چهار ZIP؛ استخراج ۱۷ محصول، ۱۳ مقاله و صفحات سازمانی از سایت رسمی | فهرست منشأ و تصاویر محلی، بدون آمار ساختگی |
| 02 — هسته | Next.js App Router، TypeScript strict، سیستم رنگ و شیشه مشترک، فونت محلی | بیلد و تایپ‌چک |
| 03 — زبان | fa / en / tr / ar / ru، RTL/LTR و آدرس زبان‌دار | تمام مسیرهای ثابت در پنج زبان؛ حفظ state در تغییر زبان |
| 04 — اجزای نمونه | انتقال دندان سه‌بعدی لندینگ، آب تعاملی، ماسکات ورود، نوبار و سایدبار، داشبورد و کروسل | فایل منشأ هر جزء و lifecycle مناسب |
| 05 — کاتالوگ | فهرست/جزئیات ۱۷ محصول، خانواده، فیلتر، جستجو، مقایسه، ذخیره و استعلام | بدون سبد خرید/قیمت/پرداخت؛ تفکیک مواد از دندان |
| 06 — وب‌سایت | لندینگ، شرکت، تولید، کیفیت، پژوهش، اسناد، دانشنامه، اخبار، رویداد، نمایندگان، همکاری و استخدام | مسیر واقعی و محتوای مرتبط یا حالت خالی صادقانه |
| 07 — ارتباط | فرم استعلام/نمونه/پشتیبانی/کیفیت/همکاری/استخدام، ورود CSV، کد پیگیری | درخواست مشترک در پورتال و CRM با ذخیرهٔ محلی |
| 08 — ورود و حساب | ورود، ثبت‌نام، بازیابی، MFA دمو، ۱۲ نقش دقیق سند، پروفایل، سازمان، درخواست، اعلان و امنیت | کنترل نمایشی نقش و نبود ادعای احراز هویت سرور |
| 09 — محتوا | CMS، صفحه‌ساز ۲۸ بلوک، رسانه، ترجمه، بازبینی، انتشار، استودیو متن/تصویر/ویدیو/صوت | ایجاد/ویرایش/بازبینی/انتشار محلی مستقل هر زبان |
| 10 — CRM | مخاطب، سازمان، سرنخ، کانبان فرصت، فعالیت، پیش‌فاکتور، نمونه، تیکت، کمپین و گزارش | CRUD، جستجو، فیلتر، تغییر مرحله، خروجی و تعامل واقعی |
| 11 — عملیات | ۱۲ بخش پایش، نقش‌ها، تنظیمات، اعلان‌ها، مهاجرت | دادهٔ نمونه برچسب‌دار و وضعیت اتصال روشن |
| 12 — تحویل | بیلد استاتیک، کد کامل، راهنمای فارسی، قرارداد API و ماتریس پوشش | بازبینی فایل/مسیر/TypeScript، بستهٔ قابل اجرا و استقرار خصوصی |

## اصل یکپارچگی
تم، جهت، زبان، محصولات و درخواست‌ها در سراسر وب‌سایت و پنل مشترک‌اند. محتوای داشبوردهای نمونه با اطلاعات مرتبط با تولید دندان مصنوعی، پژوهش، کاتالوگ و ارتباط با لابراتوار/کلینیک جایگزین می‌شود. صفحات فاقد دادهٔ عمومی معتبر نباید با گواهی، آمار، نماینده، فرصت شغلی یا خبر ساختگی پر شوند؛ در این موارد مسیر ایجاد/درخواست یا وضعیت محتوای منتشرنشده نمایش داده می‌شود.

## مرز بک‌اند
کلیدهای خصوصی در مرورگر دریافت یا ذخیره نمی‌شوند. ذخیره‌سازی محلی فقط برای اجرای مستقل قابل بررسی است. فایل `docs/BACKEND-CONTRACT.md` محل اتصال API، مدل خطا، نقش‌ها، optimistic version و نمونهٔ endpointها را توضیح خواهد داد.
