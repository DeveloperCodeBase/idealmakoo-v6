این سند نتیجهٔ کنترل نسخهٔ سوم را ثبت می‌کند. تغییرات و کنترل‌های بازطراحی جدید در [راهنمای اصلاح چهارم](REVISION-4-GUIDE.md) آمده‌اند.

تاریخ: ۲۰۲۶-۱۰-۱۷ — Next.js، TypeScript و درگاه واقعی Google AI

## دامنهٔ آزمون و بازبینی

آزمون‌ها نقش و مجوز، تفکیک دادهٔ پنل، فرمان دیررس حساب قبلی، بازبینی مستقل، تطبیق نسخهٔ انتشار، ویرایش صفحهٔ اصلی/لوگو/منو، محصول سفارشی، مشخصات منتشرشده، هویت SKU، مالکیت درخواست، پیام عمومی/داخلی، پیشنهاد تجاری، محاسبات مبلغ و CSV را پوشش می‌دهند.

۲۵ آزمون صحنه، هندسه و نرمال‌ها، ریشه‌ها، مشتق موج، حرکت روی آب، تکانه و سقوط، پایداری در نرخ فریم متفاوت، مسیر پیوستهٔ Ai Agent و ریاضی روبیک را بررسی می‌کنند. ۱۱ آزمون کروسل، هندسهٔ مرجع، عرض‌های محدود، جهت RTL و حالت‌های حرکت را پوشش می‌دهند. این‌ها کیفیت تصویر رندرشده یا تجربهٔ لمس واقعی را اثبات نمی‌کنند.

آزمون‌های درگاه AI با پاسخ کنترل‌شدهٔ سرویس، ورودی پنج زبان، بودجهٔ متن و سابقه، کلید صرفاً در هدر سرور، خطای سهمیه بدون افشای پاسخ خام، تصویر مرجع، ذخیره و مالکیت تصویر، توقف و همزمانی را بررسی می‌کنند. ۱۲ آزمون استودیو، هفت حالت تولید، مرجع معتبر PNG/JPEG/WebP، اندازه و base64، metadata واقعی و بی‌اثرشدن نتیجهٔ دیررس را پوشش می‌دهند.

بازبینی استودیو سه ایراد مشخص را نیز اصلاح کرد: لغو بارگذاری، انتخاب تصویر را قفل نمی‌کند؛ تصویر تولیدشده در صفحه یک بلوک تصویر مستقل دارد؛ پاک‌کردن متن، ویرایشگر را حذف نمی‌کند. صوت و ویدئو صریحاً متن سناریو تولید می‌کنند.

عنوان، توضیح و شعارهای متحرک هیرو با زبان انتخاب‌شده در هر پنج زبان نمایش داده می‌شوند؛ fa/ar راست‌به‌چپ و en/tr/ru چپ‌به‌راست. حرکت روی خط کامل اجرا می‌شود تا شکل حروف شکسته نشود. محتوای CMS نیز از همان زبان خوانده می‌شود. پوستهٔ صفحات، ورود، پرتال و داشبورد تمام‌عرض است؛ فرم‌ها و دیالوگ‌ها ابعاد کاربردی خود را دارند.

## سرویس واقعی

فهرست مدل‌های Google و تولید متن با `gemini-3.5-flash-lite` پاسخ واقعی HTTP 200 دادند. تولید تصویر با `gemini-nano-banana-2.1` و مدل سبک‌تر `gemini-3.1-flash-lite-image` برای حساب ارائه‌شده هر دو با HTTP 429 و `RESOURCE_EXHAUSTED` متوقف شدند. تصویر واقعی تولید نشد. اتصال تصویر و رسیدگی به خطا پیاده شده‌اند؛ موفقیت تولید تصویر پس از فراهم‌شدن سهمیه باید دوباره بررسی شود.

کلید در تنظیمات سرور است و داخل سورس یا ZIP قرار نمی‌گیرد. وضعیت تنظیمات، مدل‌ها و منابع به مرورگر برمی‌گردند؛ کلید و پاسخ خام خطای Google برنمی‌گردند. نتیجهٔ استقرار و بررسی HTTP نسخهٔ آنلاین جداگانه همراه تحویل گزارش می‌شود.

## مرز بررسی و ادامهٔ بک‌اند

مرورگر کنترل‌شده در محیط ساخت در دسترس نبود. WebGL روی دستگاه واقعی، ارزیابی بصری دارک/لایت، GPU، درگ با موس و لمس، نصب PWA و screen reader در مرورگر آزمایش نشده‌اند. بررسی کد، هندسه و فایل جای مشاهدهٔ این رفتارها را نمی‌گیرد. کنترل مسیرها بررسی فایل خروجی است، نه بازکردن تعاملی تمام صفحات.

درگاه Google AI واقعی و سروری است. داده‌های CMS/CRM، نقش‌های نمونه و انتشار محتوای نمونه همچنان مدل محلی فرانت‌اند دارند. احراز هویت نهایی، مجوز سرور، داده و انتشار مشترک و سرویس پیام باید مطابق `BACKEND-CONTRACT.md` به بک‌اند متصل شوند. نشانگر Ai Agent موتور حرکتی فرانت‌اند مستقل از API دارد.

در این محیط، CLI جداشدهٔ TypeScript در مسیر داخلی Next خروجی خالی می‌داد. `experimental.useTypeScriptCli: false` مسیر API کامپایلر TypeScript 5 را فعال می‌کند؛ بررسی نوع زمان ساخت همچنان فعال و موفق است. خطای نوع نادیده گرفته نشده است.

## بازتولید

```bash
npm ci
npm test
npm run build
npm run check
npm start
```

Node.js 24 یا جدیدتر لازم است. برای AI محلی، کلید را فقط در `.env.local` مطابق `.env.example` قرار دهید. `scripts/prepare-download.mjs` بسته و manifest هش را می‌سازد؛ `scripts/verify.mjs` خروجی را بدون سرور/مرورگر بررسی می‌کند؛ `scripts/build-worker.mjs` از همین خروجی و منابع، بستهٔ سرور و دارایی‌ها را می‌سازد.
